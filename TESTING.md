# Практична робота №8
# Звіт про тестування Student Assistant

## 1. Мета тестування

Перевірити адаптивність інтерфейсу вебзастосунку Student Assistant на різних розмірах екрана, працездатність компонентів React та стабільність відображення сторінки.

## 2. Інструменти тестування

Для тестування використовувалися:
- Google Chrome;
- Chrome DevTools;
- Device Mode;
- Console;
- Network;
- Performance.

## 3. Перевірка адаптивності

Для перевірки інтерфейсу використовувалися такі точки перелому:

- Mobile — від 320 px;
- Tablet — від 600 px;
- Desktop — від 1024 px;
- Large Desktop — від 1440 px.

Для розташування карток використано CSS Grid:
- Mobile — 1 колонка;
- Tablet — 2 колонки;
- Desktop — 3 колонки;
- Large Desktop — 4 колонки.

Заголовок і лічильник завдань адаптуються до ширини екрана за допомогою Flexbox.

## 4. Перевірка компонентів

Перевірено такі компоненти:
- Header — відображення заголовка та кількості завдань;
- TaskList — формування списку завдань;
- TaskItem — відображення назви, пріоритету та статусу завдання.

Для адаптивної зміни відображення використано React Hook `useIsDesktop` та JavaScript API `window.matchMedia()`.

## 5. Перевірка продуктивності

За допомогою Chrome DevTools виконано перевірку:
- Console — критичних помилок не виявлено;
- Network — перевірено завантаження застосунку в режимі 3G;
- Performance — виконано запис продуктивності;
- CPU throttling — перевірено роботу інтерфейсу при уповільненні процесора 4×.

Застосунок зберігав працездатність під час тестування.

## 6. Виявлення та усунення дефектів

Під час тестування було виявлено горизонтальне переповнення карток на вузьких екранах.

Для усунення проблеми застосовано:
- `width: 100%`;
- `min-width: 0`;
- `box-sizing: border-box`;
- `overflow-wrap: anywhere`.

Після виправлення картки коректно відображаються на мобільних екранах.

Також було виправлено підключення `App.css` у компоненті `App.jsx`, через що раніше не застосовувалися стилі адаптивної сітки.

## 7. Висновок

У ході практичної роботи було реалізовано адаптивний інтерфейс Student Assistant із використанням CSS Grid, Flexbox, медіазапитів, функції `clamp()` та React Hook на основі `window.matchMedia()`.

Проведено тестування інтерфейсу на різних розмірах екрана та перевірено роботу застосунку за умов обмеженої швидкості мережі й продуктивності процесора.

Виявлені недоліки усунуто. Основні функціональні та адаптивні можливості застосунку реалізовано.
